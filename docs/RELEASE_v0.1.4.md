# SchemaBatch v0.1.4

`SchemaBatch` 是一个本地桌面批处理工具，用来把评论、问卷、访谈、舆情等文本批量送入大模型，并导出结构化结果。

这一版已经提供可直接安装的 Windows 桌面包，普通用户下载后即可使用，不需要额外安装 `Python / Node.js / Rust`。

## 适合处理的任务

- 评论、问卷、访谈、舆情文本的结构化分析
- 主题分类、观点抽取、情感识别、摘要生成
- 任意“表格输入 -> 结构化输出”的轻量批处理任务

## 这版可以直接用的功能

- 导入 `CSV / XLSX / XLS`
- 在应用内录入、粘贴和整理文本数据
- 配置输入列、输出字段和提示词模板
- 批量调用模型并导出结构化结果
- 查看运行日志、结果预览和错误信息

## 安装包

- `SchemaBatch_0.1.4_x64-setup.exe`
- `SchemaBatch_0.1.4_x64_en-US.msi`

## 使用方式

1. 安装并打开应用
2. 填写你自己的模型 API Key
3. 导入表格或直接在程序内录入文本
4. 选择模板并确认输出字段
5. 运行批处理并导出结果

## 当前已包含的能力

- 图形化模板向导
- 输入预处理、输入预览、输出预检
- 批量运行、失败重试、结果预览、运行日志
- 程序内数据录入与表格编辑

## 已知事项

- 当前发布版优先支持 Windows
- 模型服务仍需用户自己提供可用的 API Key
- 如果需要从源码运行，仍需要本地开发环境
