# SchemaBatch v0.1.4

Windows 桌面发布版，下载后可直接安装使用。

## 本版可直接完成的工作

- 导入 `CSV / XLSX / XLS`
- 在应用内录入或整理文本数据
- 配置输入列、输出字段和提示词模板
- 批量调用模型并导出结构化结果

## 适合处理的任务

- 评论、问卷、访谈、舆情文本的结构化分析
- 主题分类、观点抽取、情感识别、摘要生成
- 任意“表格输入 -> 结构化输出”的轻量批处理任务

## 安装包

- `SchemaBatch_0.1.4_x64-setup.exe`
- `SchemaBatch_0.1.4_x64_en-US.msi`

## 使用说明

- 安装后直接启动应用
- 填写你自己的模型 API Key
- 导入数据或直接在程序内录入文本
- 选择模板并检查输出字段
- 运行批处理并导出结果

## 当前能力

- 图形化模板向导
- 输入预处理、输入预览、输出预检
- 批量运行、失败重试、结果预览、运行日志
- 程序内数据录入与表格编辑

## 已知事项

- 当前发布版优先支持 Windows
- 模型服务仍需用户自己提供可用的 API Key
- 如果需要从源码运行，仍需要本地开发环境
