# SchemaBatch v0.1.3

首个可直接下载安装的 Windows 发布版。

## 本版重点

- 提供 Windows 安装包，普通用户可直接安装使用
- 发布版内置批处理引擎，不要求额外安装 Python
- 保留桌面工作台主链路：导入文本或表格、配置模板、批量调用模型、导出结构化结果
- 补齐 GitHub Release 自动构建链路，后续版本可继续沿用

## 适合处理的任务

- 评论、问卷、访谈、舆情文本的结构化分析
- 主题分类、观点抽取、情感识别、摘要生成
- 任意“表格输入 -> 结构化输出”的轻量批处理任务

## 安装包

- `SchemaBatch_0.1.0_x64-setup.exe`
- `SchemaBatch_0.1.0_x64_en-US.msi`

## 使用说明

- 安装后直接启动应用
- 填写你自己的模型 API Key
- 导入 `CSV / XLSX / XLS`，或直接在程序内录入文本
- 选择模板并检查输出字段
- 运行批处理并导出结果

## 当前能力

- 图形化模板向导
- 输入预处理、输入预览、输出预检
- 批量运行、失败重试、结果预览、运行日志
- 程序内数据录入与表格编辑

## 已知边界

- 当前发布版优先支持 Windows
- 模型服务仍需用户自己提供可用的 API Key
- 首版目标是本地批处理工作台，不包含在线协作与 SaaS 能力
