# 迁移计划

## 目标

把当前根目录的 Python 原型能力，逐步迁移到桌面应用架构中，同时保持主链路始终可验证。

## 迁移顺序

1. 保留 `universal_engine.py` 作为可运行基线
2. 在 `templates/` 和 `examples/` 中沉淀真实输入、模板和输出样例
3. 用 `src/` 完成导入、配置、运行、导出的界面流转
4. 在 `src/services/` 和 `src-tauri/` 间建立执行桥
5. 再决定引擎继续用 Python 进程桥接，还是迁移到原生命令层

## 迁移原则

- 不一次性推翻现有原型
- 不在第一阶段引入服务端依赖
- 不让 UI 直接承担批处理逻辑
- 每次迁移都保证输入、运行、输出可验证
