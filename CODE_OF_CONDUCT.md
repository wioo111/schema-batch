# Code Of Conduct

## Our Standard

This project is committed to a respectful, focused, and constructive community.

Examples of behavior that contribute to a positive environment include:

- Giving actionable, technically grounded feedback
- Assuming good intent while reviewing contributions
- Respecting different experience levels and communication styles
- Staying focused on the product, code, and documented scope

Examples of unacceptable behavior include:

- Personal attacks, harassment, or discriminatory language
- Dismissing contributors without technical reasoning
- Publishing private information without explicit permission
- Deliberately derailing discussions with unrelated arguments

## Maintainer Responsibilities

Project maintainers may edit, remove, or reject comments, commits, issues, and pull requests that violate this code of conduct or the project scope.

## Scope

This code of conduct applies within project spaces, including issues, pull requests, discussions, and review comments.

## Enforcement

If you experience or witness unacceptable behavior, open a private report through the repository owner contact method configured on GitHub.

Maintainers will review reports and respond with reasonable corrective action.
